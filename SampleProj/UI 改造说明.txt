## 功能特点

1. **瀑布流布局** - 采用 2 列 GridLayoutManager 实现瀑布流效果
2. **Material Design** - 使用 Material Toolbar、Material Card 等组件
3. **下拉刷新** - 支持 SwipeRefreshLayout 下拉刷新
4. **卡片展示** - 每个示例项包含：
   - 顶部图片区域（160dp 高度）
   - 标题（18sp，粗体）
   - 描述文字（14sp，最多 3 行）
5. **点击跳转** - 点击卡片自动跳转到对应 Activity

## 图片配置说明

目前所有示例项的图片资源 ID 都设置为 `0`（使用默认占位图）。

**要配置自定义图片，请按以下步骤操作：**

### 1. 准备图片
将您的配图放入 `app/src/main/res/drawable/` 目录

建议尺寸：宽度 400px，高度 200px（2:1 比例）

### 2. 修改 MainActivity.java

找到 `loadSamples()` 方法中的 TODO 注释，替换图片资源 ID：

```java
sampleList.add(new SampleItem(
        "普通三维场景",
        "基础三维场景渲染示例，展示基本的 3D 渲染功能",
        R.drawable.sample_base,  // ← 替换为您的图片资源名
        BaseSceneActivity.class
));
```

### 3. 示例图片命名建议

## 可选优化

如需调整布局样式，可以修改以下参数：

### 调整列数（在 MainActivity.java 中）
```java
// 当前为 2 列，可改为 1 列或 3 列
GridLayoutManager layoutManager = new GridLayoutManager(this, 2);
```

### 调整卡片圆角（在 item_sample.xml 中）
```xml
app:cardCornerRadius="12dp"  <!-- 修改此值 -->
```

### 调整图片高度（在 item_sample.xml 中）
```xml
android:layout_height="160dp"  <!-- 修改此值 -->
```

## 注意事项

- 如果编译时仍有错误，请先执行 Gradle 同步
- 图片资源名称只能包含小写字母、数字和下划线
- 确保所有引用的 Activity 类在 AndroidManifest.xml 中已注册
